awk

awk is a command-line tool for processing text files, especially files organized in rows and columns.

It reads input line by line, splits each line into fields, applies rules, and prints results.

awk is especially useful for:

  • printing selected columns;

  • filtering rows;

  • performing numerical calculations;

  • computing sums and averages;

  • reformatting data files;

  • processing simulation logs;

  • extracting information from structured text.

For example, if a file contains columns such as:

time velocity pressure
0.0  1.2  10.1
0.1  1.4  10.3
0.2  1.5  10.4

then awk can easily print only the velocity column, select rows where velocity is larger than a threshold, or compute the average pressure.

The general syntax is:

awk 'program' file

A common form is:

awk '{ action }' file

For example:

awk '{print $1}' file.txt

This prints the first column of each line.

The most general form is:

awk 'pattern { action }' file

where:

  • pattern decides which lines are selected;

  • action decides what to do with those lines.

For example:

awk '$2 > 1.5 {print $0}' data.txt

means:

for lines where the second column is larger than 1.5,
print the whole line

Create a file called measurements.dat:

cat > measurements.dat
# time velocity pressure
0.0  1.2  10.1
0.1  1.4  10.3
0.2  1.5  10.4
0.3  1.7  10.8
0.4  1.6  10.6
^D

The file contains three columns:

time velocity pressure

Fields: $1, $2, $3, $0¶

awk automatically splits each input line into fields.

By default, fields are separated by spaces or tabs.

Inside an awk program:

ExpressionMeaning
$1first field
$2second field
$3third field
$0whole line

For example:

awk '{print $1}' measurements.dat

Output:

#
0.0
0.1
0.2
0.3
0.4

The first line begins with #, so the first field of that line is #.

To print the second column:

awk '{print $2}' measurements.dat

Output:

time
1.2
1.4
1.5
1.7
1.6

To print the whole line:

awk '{print $0}' measurements.dat

This is equivalent to printing every line.

Removing header or comment lines¶

Many data files contain header lines or comments.

In this example, the first line starts with #:

# time velocity pressure

We can exclude it using a pattern:

awk '$1 != "#" {print $0}' measurements.dat

Output:

0.0  1.2  10.1
0.1  1.4  10.3
0.2  1.5  10.4
0.3  1.7  10.8
0.4  1.6  10.6

Here:

$1 != "#"

means:

the first field is not equal to #

Another common method is to use a regular expression (see the dedicated lecture to regular expressions):

awk '!/^#/ {print $0}' measurements.dat

This means:

print lines that do not start with #

Explanation:

PartMeaning
/^#/lines starting with #
!/^#/lines not starting with #
{print $0}print the whole line

Printing selected columns¶

Print time and velocity:

awk '!/^#/ {print $1, $2}' measurements.dat

Output:

0.0 1.2
0.1 1.4
0.2 1.5
0.3 1.7
0.4 1.6

Print time and pressure:

awk '!/^#/ {print $1, $3}' measurements.dat

Output:

0.0 10.1
0.1 10.3
0.2 10.4
0.3 10.8
0.4 10.6
Note

By default, print separates output fields with a space.

Using printf for formatted output¶

The command print is simple, but it gives limited control over formatting.

For more control, use printf.

Example:

awk '!/^#/ {printf "%8.3f %8.3f\n", $1, $2}' measurements.dat

Output:

   0.000    1.200
   0.100    1.400
   0.200    1.500
   0.300    1.700
   0.400    1.600

The format string:

"%8.3f %8.3f\n"

means:

FormatMeaning
%8.3ffloating-point number, width 8, 3 digits after decimal point
\nnewline

Unlike print, printf does not automatically add a newline. Therefore, we usually include \n.

Another example:

awk '!/^#/ {printf "time = %.2f, velocity = %.2f\n", $1, $2}' measurements.dat

Output:

time = 0.00, velocity = 1.20
time = 0.10, velocity = 1.40
time = 0.20, velocity = 1.50
time = 0.30, velocity = 1.70
time = 0.40, velocity = 1.60

Comparison operators¶

Common comparison operators in awk are:

OperatorMeaning
==equal
!=not equal
<smaller than
<=smaller than or equal
>larger than
>=larger than or equal

Examples:

awk '$2 == 1.5 {print $0}' measurements.dat
awk '$2 != 1.5 {print $0}' measurements.dat
awk '$2 >= 1.5 {print $0}' measurements.dat

Logical operators¶

Logical operators allow us to combine conditions.

OperatorMeaning
&&and
`
!not

Examples:

awk '!/^#/ && $2 > 1.5 {print $0}' measurements.dat

means:

not a comment line and velocity larger than 1.5
awk '!/^#/ && ($2 > 1.6 || $3 > 10.7) {print $0}' measurements.dat

means:

not a comment line and either velocity > 1.6 or pressure > 10.7

--

Filtering rows with conditions¶

awk can select rows using conditions.

Print rows where velocity is larger than 1.5:

awk '!/^#/ && $2 > 1.5 {print $0}' measurements.dat

Output:

0.3  1.7  10.8
0.4  1.6  10.6

Here:

!/^#/ && $2 > 1.5

means:

line is not a comment
and
second column is larger than 1.5

Print rows where pressure is smaller than 10.5:

awk '!/^#/ && $3 < 10.5 {print $0}' measurements.dat

Output:

0.0  1.2  10.1
0.1  1.4  10.3
0.2  1.5  10.4

Print rows where velocity is between 1.4 and 1.6:

awk '!/^#/ && $2 >= 1.4 && $2 <= 1.6 {print $0}' measurements.dat

Output:

0.1  1.4  10.3
0.2  1.5  10.4
0.4  1.6  10.6

Arithmetic operations¶

awk can perform arithmetic directly.

Common arithmetic operators:

OperatorMeaning
+addition
-subtraction
*multiplication
/division
%remainder
^power

Example: multiply velocity and pressure:

awk '!/^#/ {print $1, $2*$3}' measurements.dat

Output:

0.0 12.12
0.1 14.42
0.2 15.6
0.3 18.36
0.4 16.96

Example: compute kinetic-energy-like quantity:

awk '!/^#/ {print $1, 0.5*$2*$2}' measurements.dat

Output:

0.0 0.72
0.1 0.98
0.2 1.125
0.3 1.445
0.4 1.28

Variables in awk¶

You can create variables inside an awk program.

Example:

awk '!/^#/ {u = $2; p = $3; print u, p, u*p}' measurements.dat

Output:

1.2 10.1 12.12
1.4 10.3 14.42
1.5 10.4 15.6
1.7 10.8 18.36
1.6 10.6 16.96

Here:

u = $2
p = $3

assign the second and third columns to variables.

Variables do not need to be declared before use.

The BEGIN block¶

A BEGIN block is executed before reading the input file.

Example:

awk 'BEGIN {print "time velocity"} !/^#/ {print $1, $2}' measurements.dat

Output:

time velocity
0.0 1.2
0.1 1.4
0.2 1.5
0.3 1.7
0.4 1.6

This is useful for printing headers.

Another example:

awk 'BEGIN {print "Processing file..."} {print $0}' measurements.dat

The BEGIN block runs once before any line is read.

The END block¶

An END block is executed after all input lines have been processed.

This is useful for printing final results.

Example: count data lines.

awk '!/^#/ {n += 1} END {print n}' measurements.dat

Output:

5

Explanation:

  • for every non-comment line, increase n;

  • after reading the whole file, print n.

Computing sums and averages¶

Compute the sum of velocities:

awk '!/^#/ {sum += $2} END {print sum}' measurements.dat

Output:

7.4

Compute the average velocity:

awk '!/^#/ {sum += $2; n += 1} END {print sum/n}' measurements.dat

Output:

1.48

Add a label:

awk '!/^#/ {sum += $2; n += 1} END {print "average velocity =", sum/n}' measurements.dat

Output:

average velocity = 1.48

A safer version avoids division by zero:

awk '!/^#/ {sum += $2; n += 1} END {if (n > 0) print sum/n; else print "no data"}' measurements.dat

Minimum and maximum¶

Compute the maximum velocity:

awk '!/^#/ {if ($2 > max) max = $2} END {print max}' measurements.dat

This works here because all velocities are positive. A more robust version initializes max on the first data row:

awk '!/^#/ {if (n == 0 || $2 > max) max = $2; n += 1} END {print max}' measurements.dat

Compute both minimum and maximum velocity:

awk '!/^#/ {
    if (n == 0 || $2 < min) min = $2
    if (n == 0 || $2 > max) max = $2
    n += 1
}
END {
    print "min =", min
    print "max =", max
}' measurements.dat

Output:

min = 1.2
max = 1.7

This is easier to read when written on multiple lines.

Field separator: -F¶

By default, awk splits lines using spaces and tabs.

For files with another delimiter, use -F.

Create a CSV file:

cat > particles.csv
id,x,y,z
1,0.1,0.2,0.3
2,0.4,0.5,0.6
3,0.7,0.8,0.9
^D

Print the second column:

awk -F "," '{print $2}' particles.csv

Output:

x
0.1
0.4
0.7

Built-in variables: NR, NF, FS, OFS¶

awk provides several built-in variables.

VariableMeaning
NRcurrent input line number
NFnumber of fields in the current line
FSinput field separator
OFSoutput field separator

NR: line number¶

Print each line with its line number:

awk '{print NR, $0}' measurements.dat

Output:

1 # time velocity pressure
2 0.0  1.2  10.1
3 0.1  1.4  10.3
4 0.2  1.5  10.4
5 0.3  1.7  10.8
6 0.4  1.6  10.6

Print only lines after the first:

awk 'NR > 1 {print $0}' measurements.dat

NF: number of fields¶

Print the number of fields in each line:

awk '{print NF, $0}' measurements.dat

Print the last field of each line:

awk '{print $NF}' measurements.dat

For measurements.dat, this prints:

pressure
10.1
10.3
10.4
10.8
10.6

FS: input field separator¶

Instead of using -F ",", we can set FS in a BEGIN block:

awk 'BEGIN {FS=","} {print $2}' particles.csv

OFS: output field separator¶

By default, print $1, $2 separates fields with a space.

Set OFS to change the output separator:

awk 'BEGIN {OFS=","} !/^#/ {print $1, $2}' measurements.dat

Output:

0.0,1.2
0.1,1.4
0.2,1.5
0.3,1.7
0.4,1.6

Passing shell variables to awk¶

Suppose we have a shell variable:

threshold=1.5

A common but unsafe approach is:

awk '$2 > '$threshold' {print $0}' measurements.dat

A better way is to use -v:

awk -v thr="$threshold" '!/^#/ && $2 > thr {print $0}' measurements.dat

Here:

  • threshold is a Bash variable;

  • thr is an awk variable;

  • -v thr="$threshold" passes the Bash value into awk.

Example:

threshold=1.5
awk -v thr="$threshold" '!/^#/ && $2 > thr {print $1, $2}' measurements.dat

Output:

0.3 1.7
0.4 1.6

This is the recommended method.

Using awk in pipelines¶

awk works naturally in pipelines.

Example:

grep -v '^#' measurements.dat | awk '{print $2}'

This means:

remove comment lines → print second column

However, awk can also do both tasks itself:

awk '!/^#/ {print $2}' measurements.dat

Both are correct.

Another example:

ls -l | awk '{print $9}'

This prints the ninth column of ls -l output, which is often the file name.

Warning

Parsing ls output is fragile for filenames containing spaces. For simple teaching examples it is acceptable, but for robust scripts other methods are better.

Command substitution with awk¶

The output of an awk command can be stored in a Bash variable.

Example:

avg=$(awk '!/^#/ {sum += $2; n += 1} END {print sum/n}' measurements.dat)
echo "$avg"

This stores the average velocity in the Bash variable avg.

Then it can be used later:

echo "average velocity = $avg"

Arrays in awk¶

awk supports associative arrays.

This is useful for counting occurrences.

Create a file:

cat > status.log
OK
OK
FAILED
OK
WARNING
FAILED
OK
^D

Count how many times each status appears:

awk '{count[$1] += 1} END {for (s in count) print s, count[s]}' status.log

Output may be:

OK 4
FAILED 2
WARNING 1

The order is not guaranteed.

Explanation:

count[$1] += 1

means:

increase the counter associated with the value of the first field

For example, if $1 is OK, then count["OK"] is increased.

A more compact form is:

awk '{count[$1]++} END {for (s in count) print s, count[s]}' status.log

Built-in functions¶

awk has several built-in functions.

Common numerical functions:

FunctionMeaning
sqrt(x)square root
sin(x)sine
cos(x)cosine
exp(x)exponential
log(x)natural logarithm
int(x)integer part

Example:

awk '!/^#/ {print $1, sqrt($2)}' measurements.dat

Common string functions:

FunctionMeaning
length(s)length of string
substr(s,i,n)substring of s starting at i, length n
index(s,t)position of string t inside s
tolower(s)convert to lowercase
toupper(s)convert to uppercase
gsub(r,s)replace all matches of regex r with string s

Example:

awk '{print toupper($0)}' status.log

Example using gsub:

awk '{gsub(/OK/, "SUCCESS"); print $0}' status.log

This replaces all occurrences of OK with SUCCESS.

Output redirection from awk¶

awk can redirect output to files.

Example:

awk '!/^#/ && $2 > 1.5 {print $0 > "large_velocity.dat"}' measurements.dat

This writes selected rows to large_velocity.dat.

Inspect:

cat large_velocity.dat

Output:

0.3  1.7  10.8
0.4  1.6  10.6

You can also append using >>:

awk '!/^#/ && $2 > 1.5 {print $0 >> "large_velocity.dat"}' measurements.dat
Tip

For simple cases, shell redirection is usually clearer:

awk '!/^#/ && $2 > 1.5 {print $0}' measurements.dat > large_velocity.dat

Reading an awk program from a file¶

Short awk programs can be written directly on the command line.

For longer programs, use a script file.

Create a file called average.awk:

cat > average.awk
!/^#/ {
    sum += $2
    n += 1
}

END {
    if (n > 0)
        print "average velocity =", sum/n
    else
        print "no data"
}
^D

Run it:

awk -f average.awk measurements.dat

Output:

average velocity = 1.48

The option:

-f average.awk

means:

read the awk program from average.awk

NR versus FNR¶

When processing one file, NR and FNR are the same.

When processing multiple files:

VariableMeaning
NRtotal record number across all files
FNRrecord number within the current file

Example:

awk '{print NR, FNR, $0}' measurements.dat measurements.dat

During the first file:

NR = FNR

During the second file:

NR continues increasing
FNR restarts from 1

This distinction is useful in two-pass processing and when comparing files.

Summary¶

awk '{print $1}' file.txt                         # print first column
awk '{print $1, $3}' file.txt                     # print first and third columns
awk '{print $0}' file.txt                         # print whole line

awk '!/^#/ {print $0}' file.txt                   # print lines that do not start with #
awk '$2 > 1.5 {print $0}' file.txt                # print rows where second column is larger than 1.5
awk '$2 >= 1.4 && $2 <= 1.6 {print $0}' file.txt  # print rows where second column is in a range

awk '{print $2*$3}' file.txt                      # multiply second and third columns
awk '{sum += $2} END {print sum}' file.txt        # sum second column
awk '{sum += $2; n++} END {print sum/n}' file.txt # average second column

awk -F "," '{print $2}' file.csv                  # use comma as input field separator
awk 'BEGIN {OFS=","} {print $1, $2}' file.txt     # use comma as output field separator

awk '{print NR, $0}' file.txt                     # print line number and line
awk '{print NF, $0}' file.txt                     # print number of fields and line
awk '{print $NF}' file.txt                        # print last field

awk -v thr=1.5 '$2 > thr {print $0}' file.txt     # pass variable to awk
awk '{count[$1]++} END {for (x in count) print x, count[x]}' file.txt # count occurrences

awk -f script.awk file.txt                        # read awk program from file

Exercise¶

Create this file:

cat > run.log
step 0 time 0.00 velocity 1.2 energy 10.5 status OK
step 1 time 0.10 velocity 1.4 energy 10.2 status OK
step 2 time 0.20 velocity 1.5 energy 11.8 status WARNING
step 3 time 0.30 velocity 1.7 energy 10.1 status OK
step 4 time 0.40 velocity 1.6 energy 15.9 status FAILED
step 5 time 0.50 velocity 1.3 energy 9.9 status OK
^D

Try:

awk '{print $2, $4, $6}' run.log
awk '$6 > 11.0 {print $0}' run.log
awk '$8 == "OK" {print $0}' run.log
awk '$8 != "OK" {print $0}' run.log
awk '{sum += $6; n++} END {print sum/n}' run.log
awk '{if (n == 0 || $4 > max) max = $4; n++} END {print max}' run.log
awk '{count[$8]++} END {for (s in count) print s, count[s]}' run.log
awk 'BEGIN {print "# step velocity energy"} {print $2, $4, $6}' run.log
awk -v thr=1.5 '$4 > thr {print $2, $4}' run.log

These commands cover the most common uses of awk: selecting columns, filtering rows, computing statistics, formatting output, and counting occurrences.
