# File Input/Output: Reading and Writing Files

Suppose a text file contains the coordinates of points belonging to a particle.
Each point has an identifier and three coordinates. We want to read the points,
calculate their centroid, and write the result to another file.

The input file has this format:

```text
number_of_points dataset_name
point_id x y z
point_id x y z
...
```

For example, `points.txt` could contain:

```text
4 Particle_A
1 1.0 2.0 3.0
2 4.0 5.0 6.0
3 7.0 8.0 9.0
4 10.0 11.0 12.0
```

Since all points have equal weight, their centroid is the coordinate-wise
average, `(5.5, 6.5, 7.5)`.

Run the program with the input and output filenames:

```bash
./centroid points.txt results.txt
```

The program reads the point count and checks that it is positive. It assumes
the remaining point records follow the format shown above, computes the
centroid, and writes the results to the output file.

## Algorithm

Before looking at the C implementation, here is the sequence of steps:

```text
READ the input filename and output filename from the command line
OPEN the input file
READ the number of points and the dataset name
ALLOCATE one array for identifiers and three arrays for coordinates
FOR each point
    READ its identifier into points_id
    READ its coordinates into points_x, points_y, points_z
END FOR
CLOSE the input file
centroid_x = AVERAGE(points_x)
centroid_y = AVERAGE(points_y)
centroid_z = AVERAGE(points_z)
OPEN the output file
WRITE the dataset name, point count, centroid, and coordinates
CLOSE the output file
RELEASE the four arrays
```

The code below follows this order. For clarity, it checks the command-line
arguments, file openings, header, and memory allocation. It assumes that the
remaining point records follow the format shown above.

## Complete C program

```c
#include <stdio.h>
#include <stdlib.h>

double average(const double values[], int n) {
    double sum = 0.0;

    for (int i = 0; i < n; ++i) {
        sum += values[i];
    }

    return sum / n;
}

int main(int argc, char *argv[]) {
    if (argc != 3) {
        fprintf(stderr, "Usage: %s <input_file> <output_file>\n", argv[0]);
        return EXIT_FAILURE;
    }

    FILE *input_file = fopen(argv[1], "r");
    if (input_file == NULL) {
        fprintf(stderr, "Error opening input file '%s'.\n", argv[1]);
        return EXIT_FAILURE;
    }

    int n;
    char dataset_name[100];
    if (fscanf(input_file, "%d %99s", &n, dataset_name) != 2 || n <= 0) {
        fprintf(stderr, "Invalid input header.\n");
        fclose(input_file);
        return EXIT_FAILURE;
    }

    int *points_id = malloc(n * sizeof *points_id);
    double *points_x = malloc(n * sizeof *points_x);
    double *points_y = malloc(n * sizeof *points_y);
    double *points_z = malloc(n * sizeof *points_z);

    if (points_id == NULL || points_x == NULL ||
        points_y == NULL || points_z == NULL) {
        fprintf(stderr, "Could not allocate memory for the points.\n");
        free(points_id);
        free(points_x);
        free(points_y);
        free(points_z);
        fclose(input_file);
        return EXIT_FAILURE;
    }

    /* The remaining input is assumed to follow the format shown above. */
    for (int i = 0; i < n; ++i) {
        fscanf(input_file, "%d %lf %lf %lf",
               &points_id[i], &points_x[i],
               &points_y[i], &points_z[i]);
    }
    fclose(input_file);

    double centroid_x = average(points_x, n);
    double centroid_y = average(points_y, n);
    double centroid_z = average(points_z, n);

    /* Open the output only after the input has been read. */
    FILE *output_file = fopen(argv[2], "w");
    if (output_file == NULL) {
        fprintf(stderr, "Error opening output file '%s'.\n", argv[2]);
        free(points_id);
        free(points_x);
        free(points_y);
        free(points_z);
        return EXIT_FAILURE;
    }

    fprintf(output_file, "Dataset: %s\n", dataset_name);
    fprintf(output_file, "Number of points: %d\n", n);
    fprintf(output_file, "Centroid: (%.2f, %.2f, %.2f)\n",
            centroid_x, centroid_y, centroid_z);
    fprintf(output_file, "Point coordinates:\n");

    for (int i = 0; i < n; ++i) {
        fprintf(output_file, "Point %d: (%.2f, %.2f, %.2f)\n",
                points_id[i], points_x[i],
                points_y[i], points_z[i]);
    }

    fclose(output_file);
    free(points_id);
    free(points_x);
    free(points_y);
    free(points_z);

    printf("Centroid written to %s\n", argv[2]);
    return EXIT_SUCCESS;
}
```

## Compile and run the program

Save the code as `centroid.c`, compile it, and run it with the example input:

```bash
gcc centroid.c -o centroid
./centroid points.txt results.txt
cat results.txt
```

The output file contains:

```text
Dataset: Particle_A
Number of points: 4
Centroid: (5.50, 6.50, 7.50)
Point coordinates:
Point 1: (1.00, 2.00, 3.00)
Point 2: (4.00, 5.00, 6.00)
Point 3: (7.00, 8.00, 9.00)
Point 4: (10.00, 11.00, 12.00)
```

Use different paths for input and output. Opening the input file itself as the
output would truncate it after it has been read.

## Understanding the program

### Coordinate arrays and centroid

The program stores the data in four arrays:

- `points_id[i]` contains the identifier of point `i`;
- `points_x[i]`, `points_y[i]`, and `points_z[i]` contain its coordinates.

The same index identifies the same point in all four arrays. For the first
record in the example, `points_id[0]` is 1 and its coordinates are
`points_x[0] = 1.0`, `points_y[0] = 2.0`, and `points_z[0] = 3.0`.

The function `average` receives one coordinate array and its length. It adds
the values and divides by `n`. Calling it separately for x, y, and z gives
the three coordinates of the centroid:

```c
double centroid_x = average(points_x, n);
double centroid_y = average(points_y, n);
double centroid_z = average(points_z, n);
```

Because every point has equal weight, this is their centroid; particles with
different masses require a mass-weighted average. The header check ensures
that `n` is positive before division.

### Command-line arguments

The program expects two filenames in addition to its own name, so argc must
be 3. argv[1] is the input filename and argv[2] is the output filename.

### Opening files with fopen

FILE * identifies an open C file stream. The call fopen(argv[1], "r") opens
an existing file for reading. If it fails, it returns NULL and the program
prints an error. The "w" mode creates the output file or clears it if it
already exists. The program opens it only after reading the input, so the
output file is not truncated before the data have been loaded.

Common modes include "r" for reading, "w" for writing, and "a" for appending.
Add b, as in "rb", for binary files on systems that distinguish text and binary
streams. A + allows both reading and writing.

### Reading data with fscanf

The header is read with:

```c
fscanf(input_file, "%d %99s", &n, dataset_name)
```

The %d conversion reads an integer into n. The %s conversion reads a word
into the character array; the width 99 leaves room for the terminating null
character in dataset_name[100]. The function returns the number of values it
read, so the program checks that both header fields were obtained and that
n is positive.

Each point record uses `%d` for its identifier and `%lf` for its three double
coordinates. The addresses `&points_id[i]`, `&points_x[i]`, `&points_y[i]`,
and `&points_z[i]` tell `fscanf` where to store the values. In this introductory example, we assume every point record is
present and correctly formatted. A more defensive reader would check that
each fscanf call returns 4 before using the values.

### Allocating the arrays

After reading `n`, the program allocates space for one integer identifier
and three double coordinates per point:

```c
int *points_id = malloc(n * sizeof *points_id);
double *points_x = malloc(n * sizeof *points_x);
double *points_y = malloc(n * sizeof *points_y);
double *points_z = malloc(n * sizeof *points_z);
```

Each call allocates a contiguous array. For example, `sizeof *points_x` is
the size of one double, so `n * sizeof *points_x` is the number of bytes
needed for the x coordinates.

The program checks that all four allocations succeeded before using them.
If one fails, it releases any arrays already allocated; `free(NULL)` is
allowed. At the end, each successful allocation has its own matching `free`.

### Writing with fprintf

fprintf works like printf, with the output stream as its first argument.
Each %.2f in the centroid line prints a coordinate with two digits after the
decimal point.

### Closing files with fclose

fclose closes a stream and flushes buffered output. The program closes the
input after reading and the output after writing. Closing files releases the
resources associated with the streams; for output, it also lets the C library
report errors that occur while flushing buffered data.

### fopen and open

fopen is part of the C standard library and provides streams for formatted
I/O such as fprintf and fscanf. On POSIX systems, open is a lower-level
interface that returns a file descriptor. This example uses fopen because
its stream interface is convenient for formatted text files.
