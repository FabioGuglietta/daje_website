# Dedicated lecture: `sed`

## 1. What is `sed`?

`sed` means **stream editor**.

It is a command-line tool used to process text line by line. It reads input, applies editing commands, and writes the result to standard output.

The general idea is:

```text
input text → sed command → modified text
```

For example:

```bash
sed 's/old/new/' file.txt
```

means:

```text
read file.txt, replace old with new, print the result
```

By default, `sed` does **not** modify the original file. It prints the modified text to the screen.

This makes `sed` useful for:

- replacing words or patterns;
- deleting lines;
- printing selected lines;
- editing configuration files;
- modifying many files automatically;
- processing text inside shell scripts;
- building pipelines with other Unix commands.

---

## 2. General syntax

The general syntax of `sed` is:

```bash
sed [options] 'command' file
```

where:

- `command` is the editing instruction;
- `file` is the input file;
- `[options]` are optional flags that modify the behavior of `sed`.

For example:

```bash
sed 's/cow/goat/' file.txt
```

Here:

- `s/cow/goat/` is the `sed` command;
- `s` means substitute;
- `cow` is the text to search for;
- `goat` is the replacement text;
- `file.txt` is the input file.

If no file is given, `sed` reads from standard input:

```bash
echo "The cow is here" | sed 's/cow/goat/'
```

Output:

```text
The goat is here
```

## 3. Preparing an example file

Create a file:

```bash
cat > animals.txt
The cow is in the field.
The cow is a calm animal.
The dog is in the garden.
The cows are eating grass.
A cow can produce milk.
^D
```

Inspect it:

```bash
cat animals.txt
```

Output:

```text
The cow is in the field.
The cow is a calm animal.
The dog is in the garden.
The cows are eating grass.
A cow can produce milk.
```

We will use this file in the next examples.

---

## 4. Basic substitution

The most common `sed` command is substitution:

```bash
sed 's/old/new/' file.txt
```

The letter `s` means **substitute**.

Example:

```bash
sed 's/cow/goat/' animals.txt
```

Output:

```text
The goat is in the field.
The goat is a calm animal.
The dog is in the garden.
The goats are eating grass.
A goat can produce milk.
```

By default, `sed` replaces only the **first occurrence** of the pattern on each line.

---

## 5. Replacing all occurrences on a line

Create another file:

```bash
cat > repeated.txt
cow cow cow
dog cow dog
cow dog cow
^D
```

Run:

```bash
sed 's/cow/goat/' repeated.txt
```

Output:

```text
goat cow cow
dog goat dog
goat dog cow
```

Only the first `cow` on each line is replaced.

To replace **all occurrences** on each line, add `g`:

```bash
sed 's/cow/goat/g' repeated.txt
```

Output:

```text
goat goat goat
dog goat dog
goat dog goat
```

The `g` means **global**, but only globally on each line.

---

## 6. Saving the result to another file

By default, `sed` prints the modified text to the terminal.

To save the result to a file, use redirection:

```bash
sed 's/cow/goat/g' animals.txt > animals_modified.txt
```

Now inspect the new file:

```bash
cat animals_modified.txt
```

The original file is unchanged:

```bash
cat animals.txt
```

This is the safest way to use `sed` while learning it.

---

## 7. Editing files in place with `sed -i`

To modify the original file directly, use the option `-i`.

On Linux:

```bash
sed -i 's/cow/goat/g' animals.txt
```

On macOS:

```bash
sed -i '' 's/cow/goat/g' animals.txt
```

The difference is important. BSD/macOS `sed` requires an argument after `-i`, even if it is an empty string.

> [!WARNING]
> Be careful with `sed -i`.
>
> It modifies the file directly. If the command is wrong, the original file may be damaged.
>
> A safer workflow is:
>
> ```bash
> sed 's/old/new/g' file.txt > new_file.txt
> ```
>
> Then inspect `new_file.txt` before replacing the original file.

A safer Linux version creates a backup:

```bash
sed -i.bak 's/cow/goat/g' animals.txt
```

This modifies `animals.txt` and saves the old version as:

```text
animals.txt.bak
```

On macOS, the same syntax also works:

```bash
sed -i.bak 's/cow/goat/g' animals.txt
```

## 8. Choosing another delimiter

The substitution command usually uses `/` as a delimiter:

```bash
sed 's/old/new/' file.txt
```

However, this becomes inconvenient when the text contains `/`.

Example:

```bash
sed 's/\/home\/m.sega\/data/\/scratch\/m.sega\/data/' paths.txt
```

This is hard to read because every `/` inside the path must be escaped.

`sed` allows other delimiters:

```bash
sed 's#/home/m.sega/data#/scratch/m.sega/data#' paths.txt
```

or:

```bash
sed 's|/home/m.sega/data|/scratch/m.sega/data|' paths.txt
```

These are equivalent and much clearer.

Example:

```bash
cat > paths.txt
/home/m.sega/data/input.dat
/home/m.sega/data/output.dat
^D
```

Run:

```bash
sed 's|/home/m.sega/data|/scratch/m.sega/data|' paths.txt
```

Output:

```text
/scratch/m.sega/data/input.dat
/scratch/m.sega/data/output.dat
```

## 9. Replacing only specific occurrences

By default:

```bash
sed 's/cow/goat/' file.txt
```

replaces the first occurrence on each line.

With `g`:

```bash
sed 's/cow/goat/g' file.txt
```

it replaces all occurrences on each line.

You can also replace only the second occurrence:

```bash
sed 's/cow/goat/2' repeated.txt
```

Example input:

```text
cow cow cow
dog cow dog
cow dog cow
```

Output:

```text
cow goat cow
dog cow dog
cow dog goat
```

Only lines with at least two matches are changed.

Replace the third occurrence:

```bash
sed 's/cow/goat/3' repeated.txt
```

## 10. Case-sensitive matching

By default, `sed` is case-sensitive.

Create a file:

```bash
cat > case.txt
Cow
cow
COW
cOw
^D
```

Run:

```bash
sed 's/cow/goat/' case.txt
```

Output:

```text
Cow
goat
COW
cOw
```

Only lowercase `cow` is replaced.

With GNU `sed`, you can use `I` for case-insensitive matching:

```bash
sed 's/cow/goat/I' case.txt
```

Output:

```text
goat
goat
goat
goat
```

> [!NOTE]
> The `I` flag is supported by GNU `sed`, common on Linux.
>
> It may not be portable to all `sed` implementations.

A more portable solution is to use a regular expression:

```bash
sed 's/[cC][oO][wW]/goat/' case.txt
```

## 11. Deleting lines

The command `d` deletes lines.

Create a file:

```bash
cat > log.txt
INFO starting simulation
INFO reading input
WARNING time step is large
INFO running
ERROR simulation failed
INFO finished
^D
```

Delete lines containing `WARNING`:

```bash
sed '/WARNING/d' log.txt
```

Output:

```text
INFO starting simulation
INFO reading input
INFO running
ERROR simulation failed
INFO finished
```

Delete lines containing `ERROR`:

```bash
sed '/ERROR/d' log.txt
```

Delete both `WARNING` and `ERROR` lines:

```bash
sed '/WARNING/d; /ERROR/d' log.txt
```

or:

```bash
sed -e '/WARNING/d' -e '/ERROR/d' log.txt
```

## 12. Printing selected lines

By default, `sed` prints every line after processing it.

To print only selected lines, use `-n`.

The option `-n` suppresses automatic printing.

Then use the command `p` to print selected lines.

Print line 3:

```bash
sed -n '3p' log.txt
```

Output:

```text
WARNING time step is large
```

Print lines 2 to 4:

```bash
sed -n '2,4p' log.txt
```

Output:

```text
INFO reading input
WARNING time step is large
INFO running
```

Print lines containing `INFO`:

```bash
sed -n '/INFO/p' log.txt
```

Print lines containing `ERROR`:

```bash
sed -n '/ERROR/p' log.txt
```

This is similar to `grep`, but `sed` can also edit the selected lines.

---

## 13. Line addresses

Many `sed` commands can be restricted to specific lines.

The general form is:

```bash
sed 'address command' file
```

Examples:

```bash
sed '3d' file.txt
```

deletes line 3.

```bash
sed '2,5d' file.txt
```

deletes lines 2 to 5.

```bash
sed '1,3p' file.txt
```

prints lines 1 to 3, but because automatic printing is enabled, this duplicates those lines.

To print only lines 1 to 3:

```bash
sed -n '1,3p' file.txt
```

Useful address forms:

```text
3        line 3
2,5      lines from 2 to 5
/pat/    lines matching pattern
$        last line
1,$      from first to last line
```

Examples:

```bash
sed -n '$p' log.txt
```

prints the last line.

```bash
sed '$d' log.txt
```

deletes the last line.

```bash
sed '1d' log.txt
```

deletes the first line.

```bash
sed '1,2d' log.txt
```

deletes the first two lines.

## 14. Applying substitutions only to selected lines

You can combine addresses and substitutions.

Replace `INFO` with `MESSAGE` only on line 1:

```bash
sed '1s/INFO/MESSAGE/' log.txt
```

Replace `INFO` with `MESSAGE` only between lines 1 and 3:

```bash
sed '1,3s/INFO/MESSAGE/' log.txt
```

Replace `INFO` with `MESSAGE` only on lines containing `starting`:

```bash
sed '/starting/s/INFO/MESSAGE/' log.txt
```

Replace `INFO` with `MESSAGE` on all lines except those containing `ERROR`:

```bash
sed '/ERROR/!s/INFO/MESSAGE/' log.txt
```

Here `!` means **not**.

So:

```text
/ERROR/!s/INFO/MESSAGE/
```

means:

```text
on lines that do not match ERROR, replace INFO with MESSAGE
```

## 15. Regular expressions in `sed`

`sed` uses regular expressions to match patterns.

Create a file:

```bash
cat > numbers.txt
step 1
step 12
step 123
time 0.01
time 10.5
value abc
^D
```

### Match digits

In basic regular expressions, digits can be matched with:

```text
[0-9]
```

Example:

```bash
sed -n '/[0-9]/p' numbers.txt
```

This prints lines containing at least one digit.

### Match letters

```bash
sed -n '/[a-z]/p' numbers.txt
```

prints lines containing lowercase letters.

### Match beginning of line

The symbol `^` matches the beginning of a line.

```bash
sed -n '/^step/p' numbers.txt
```

prints lines starting with `step`.

### Match end of line

The symbol `$` matches the end of a line.

```bash
sed -n '/5$/p' numbers.txt
```

prints lines ending with `5`.

### Match any character

The dot `.` matches any single character.

```bash
sed -n '/step ./p' numbers.txt
```

matches:

```text
step 1
```

but also the beginning of longer strings such as:

```text
step 12
step 123
```

because the pattern only requires `step ` followed by at least one character.

### Repetition

In basic `sed` regular expressions, some repetition symbols must be escaped.

For example, `\+` means “one or more” in GNU/BSD `sed` basic regular expressions:

```bash
sed -n '/[0-9]\+/p' numbers.txt
```

This prints lines containing one or more digits.

In extended regular expressions, use `-E`:

```bash
sed -E -n '/[0-9]+/p' numbers.txt
```

With `-E`, the `+` does not need a backslash.

---

## 16. Basic versus extended regular expressions

By default, `sed` uses **basic regular expressions**.

With the option `-E`, `sed` uses **extended regular expressions**.

Example without `-E`:

```bash
sed -n '/step [0-9]\+/p' numbers.txt
```

Example with `-E`:

```bash
sed -E -n '/step [0-9]+/p' numbers.txt
```

The second version is often easier to read.

Common extended regular expression syntax:

| Pattern | Meaning |
|---|---|
| `.` | any single character |
| `[abc]` | one character: `a`, `b`, or `c` |
| `[0-9]` | one digit |
| `[a-z]` | one lowercase letter |
| `^` | beginning of line |
| `$` | end of line |
| `+` | one or more repetitions |
| `*` | zero or more repetitions |
| `?` | zero or one repetition |
| `a|b` | `a` or `b` |
| `( ... )` | group |

Example:

```bash
sed -E -n '/^(step|time)/p' numbers.txt
```

prints lines starting with either `step` or `time`.

---

## 17. Capturing groups and backreferences

Capturing groups allow us to reuse matched text.

With extended regular expressions, groups are written with parentheses:

```text
(...)
```

Matched groups can be reused as:

```text
\1, \2, \3, ...
```

Create a file:

```bash
cat > names.txt
Guglietta Fabio
Einstein Albert
Curie Marie
^D
```

Swap surname and name:

```bash
sed -E 's/([A-Za-z]+) ([A-Za-z]+)/\2 \1/' names.txt
```

Output:

```text
Fabio Guglietta
Albert Einstein
Marie Curie
```

Explanation:

```text
([A-Za-z]+)     first group: surname
space
([A-Za-z]+)     second group: name
```

Replacement:

```text
\2 \1
```

means:

```text
second group, then first group
```

Another example:

```bash
cat > parameters.txt
dt = 0.01
nsteps = 100
viscosity = 0.1
^D
```

Normalize spaces around `=`:

```bash
sed -E 's/[[:space:]]*=[[:space:]]*/ = /' parameters.txt
```

Output:

```text
dt = 0.01
nsteps = 100
viscosity = 0.1
```

Here:

```text
[[:space:]]*
```

means zero or more whitespace characters.

---

## 18. The `&` symbol in replacements

In the replacement part of a substitution, `&` means “the entire matched text”.

Example:

```bash
cat > values.txt
value 10
value 20
value 30
^D
```

Put brackets around numbers:

```bash
sed -E 's/[0-9]+/[&]/' values.txt
```

Output:

```text
value [10]
value [20]
value [30]
```

Here `&` is replaced by the matched number.

Another example:

```bash
sed -E 's/value/& =/' values.txt
```

Output:

```text
value = 10
value = 20
value = 30
```

---

## 19. Escaping special characters

Some characters have special meaning in `sed` patterns or replacements.

Common examples:

| Character | Meaning |
|---|---|
| `.` | any character |
| `*` | repetition |
| `[` `]` | character class |
| `^` | beginning of line |
| `$` | end of line |
| `/` | default delimiter |
| `&` | matched text in replacement |
| `\` | escape character |

To match a literal dot, escape it:

```bash
sed 's/0\.1/0.2/' file.txt
```

Without escaping, `.` means any character.

To replace a literal `&`, escape it in the replacement:

```bash
echo "A and B" | sed 's/and/\&/'
```

Output:

```text
A & B
```

To replace `/`, either escape it:

```bash
sed 's/\/old\/path/\/new\/path/' file.txt
```

or use another delimiter:

```bash
sed 's|/old/path|/new/path|' file.txt
```

## 20. Insert, append, and change lines

`sed` can insert, append, or replace whole lines.

Commands:

| Command | Meaning |
|---|---|
| `i` | insert before matching line |
| `a` | append after matching line |
| `c` | change matching line |

Create a file:

```bash
cat > config.txt
dt = 0.01
nsteps = 100
viscosity = 0.1
^D
```

### Insert before a line

Insert a line before `nsteps`:

```bash
sed '/nsteps/i output_interval = 10' config.txt
```

Output:

```text
dt = 0.01
output_interval = 10
nsteps = 100
viscosity = 0.1
```

### Append after a line

Append a line after `nsteps`:

```bash
sed '/nsteps/a output_interval = 10' config.txt
```

Output:

```text
dt = 0.01
nsteps = 100
output_interval = 10
viscosity = 0.1
```

### Change a line

Replace the line containing `nsteps`:

```bash
sed '/nsteps/c nsteps = 1000' config.txt
```

Output:

```text
dt = 0.01
nsteps = 1000
viscosity = 0.1
```

> [!NOTE]
> Syntax for multi-line insertions can differ slightly between GNU `sed` and BSD/macOS `sed`.
>
> For simple one-line insertions, the examples above are usually sufficient in modern implementations.

## 21. Multiple commands

You can apply multiple `sed` commands in one call.

Use `;`:

```bash
sed 's/cow/goat/g; s/dog/cat/g' animals.txt
```

or use multiple `-e` options:

```bash
sed -e 's/cow/goat/g' -e 's/dog/cat/g' animals.txt
```

Example:

```bash
sed -e '/WARNING/d' -e 's/INFO/MESSAGE/' log.txt
```

This:

1. deletes lines containing `WARNING`;
2. replaces `INFO` with `MESSAGE`.

---

## 22. Reading commands from a sed script

For more complex edits, put commands in a file.

Create a sed script:

```bash
cat > edit.sed
s/INFO/MESSAGE/g
s/WARNING/CAUTION/g
/ERROR/d
^D
```

Apply it:

```bash
sed -f edit.sed log.txt
```

Here:

```text
-f edit.sed
```

means:

```text
read sed commands from edit.sed
```

This is useful when edits become too long to write on one command line.

## 23. Using shell variables with `sed`

Suppose we have:

```bash
old="cow"
new="goat"
```

This will **not** expand the variables:

```bash
sed 's/$old/$new/g' animals.txt
```

because single quotes prevent Bash expansion.

Use double quotes:

```bash
sed "s/$old/$new/g" animals.txt
```

Example:

```bash
old="cow"
new="goat"
sed "s/$old/$new/g" animals.txt
```

However, be careful if variables contain `/`.

For paths, use another delimiter:

```bash
old="/home/m.sega/data"
new="/scratch/m.sega/data"
sed "s|$old|$new|g" paths.txt
```

> [!WARNING]
> When using variables inside `sed`, make sure that the variable values do not contain unexpected special characters.
>
> If they do, they may be interpreted as part of a regular expression or replacement pattern.

## 24. Practical example: editing an input file

Suppose we have a simulation input file:

```bash
cat > inputfile
dt = 0.01
nsteps = 100
restart = false
output_interval = 10
^D
```

Change the time step:

```bash
sed 's/^dt = .*/dt = 0.005/' inputfile
```

Change the number of steps:

```bash
sed 's/^nsteps = .*/nsteps = 1000/' inputfile
```

Activate restart:

```bash
sed 's/^restart = .*/restart = true/' inputfile
```

Apply all changes and save to a new file:

```bash
sed -e 's/^dt = .*/dt = 0.005/' \
    -e 's/^nsteps = .*/nsteps = 1000/' \
    -e 's/^restart = .*/restart = true/' \
    inputfile > inputfile_new
```

Inspect the result:

```bash
cat inputfile_new
```

Output:

```text
dt = 0.005
nsteps = 1000
restart = true
output_interval = 10
```

After checking the result, replace the original file:

```bash
mv inputfile_new inputfile
```

## 25. Practical example: editing many files

Suppose we have several files:

```text
run1/inputfile
run2/inputfile
run3/inputfile
```

To change `restart = false` to `restart = true` in all of them:

```bash
sed -i.bak 's/^restart = false/restart = true/' run*/inputfile
```

This modifies each file and creates backups:

```text
run1/inputfile.bak
run2/inputfile.bak
run3/inputfile.bak
```

To check the changes:

```bash
grep "restart" run*/inputfile
```

To remove the backup files after checking:

```bash
rm run*/inputfile.bak
```

> [!WARNING]
> Before using `sed -i` on many files, first test without `-i` on one file.
>
> Example:
>
> ```bash
> sed 's/^restart = false/restart = true/' run1/inputfile
> ```

## 26. Practical example: replacing only uncommented lines

Suppose an input file contains:

```bash
cat > inputfile
# restart = false
restart = false
other_parameter = 10
^D
```

If we run:

```bash
sed 's/restart = false/restart = true/' inputfile
```

both commented and uncommented occurrences may be modified.

To modify only lines that do not start with `#`:

```bash
sed '/^[[:space:]]*#/!s/restart = false/restart = true/' inputfile
```

Explanation:

```text
/^[[:space:]]*#/    lines starting with optional spaces followed by #
!                   not those lines
s/old/new/          perform substitution
```

So the command means:

```text
on lines that are not comments, replace restart = false with restart = true
```

## 27. Practical example: extracting a block of lines

Suppose we have:

```bash
cat > report.txt
Header
BEGIN DATA
1 2 3
4 5 6
7 8 9
END DATA
Footer
^D
```

Print from `BEGIN DATA` to `END DATA`:

```bash
sed -n '/BEGIN DATA/,/END DATA/p' report.txt
```

Output:

```text
BEGIN DATA
1 2 3
4 5 6
7 8 9
END DATA
```

Remove the markers:

```bash
sed -n '/BEGIN DATA/,/END DATA/p' report.txt | sed '/BEGIN DATA/d; /END DATA/d'
```

Output:

```text
1 2 3
4 5 6
7 8 9
```

## 28. Hold space and pattern space

For advanced `sed`, it is useful to know that `sed` works with two internal buffers:

- the **pattern space**;
- the **hold space**.

The **pattern space** contains the current line being processed.

The **hold space** is an auxiliary storage area where text can be temporarily saved.

Most common `sed` commands use only the pattern space.

Advanced commands can exchange text between pattern space and hold space.

Common commands:

| Command | Meaning |
|---|---|
| `h` | copy pattern space to hold space |
| `H` | append pattern space to hold space |
| `g` | copy hold space to pattern space |
| `G` | append hold space to pattern space |
| `x` | exchange pattern space and hold space |
| `N` | append next input line to pattern space |
| `D` | delete first line of pattern space and restart cycle |
| `P` | print first line of pattern space |

These commands are powerful but harder to read. For complex logic, `awk`, Perl, or Python may be clearer.

## 29. Example using `N`: editing across two lines

Normally, `sed` processes one line at a time.

Create a file:

```bash
cat > multiline.txt
first line
second line
third line
fourth line
^D
```

The command `N` appends the next line to the pattern space.

Example:

```bash
sed 'N;s/first line\nsecond line/first and second line/' multiline.txt
```

Output:

```text
first and second line
third line
fourth line
```

This works because `N` temporarily puts two lines into the pattern space, separated by `\n`.

---

## 30. Example using hold space: duplicating previous line

Create:

```bash
cat > lines.txt
one
two
three
^D
```

A simple hold-space example:

```bash
sed 'x;G' lines.txt
```

Output will include interactions between the current line and the previous hold-space content. This kind of command is useful for advanced transformations, but it is difficult to read for beginners.

A clearer practical example is usually better handled with `awk`.

> [!NOTE]
> `sed` can solve many advanced text-processing problems, but readability matters.
>
> Use `sed` for simple line-based transformations.
>
> Use `awk` for column-based processing.
>
> Use Python for complex parsing or multi-step logic.

## 31. Common `sed` commands

| Command | Meaning |
|---|---|
| `s/old/new/` | replace first occurrence of `old` with `new` on each line |
| `s/old/new/g` | replace all occurrences of `old` with `new` on each line |
| `/pattern/d` | delete lines matching `pattern` |
| `3d` | delete line 3 |
| `2,5d` | delete lines 2 to 5 |
| `-n '3p'` | print only line 3 |
| `-n '2,5p'` | print only lines 2 to 5 |
| `/pattern/s/old/new/` | substitute only on lines matching `pattern` |
| `/pattern/!s/old/new/` | substitute only on lines not matching `pattern` |
| `s/[0-9]/X/g` | replace all digits with `X` |
| `s|/old/path|/new/path|g` | replace paths using `|` as delimiter |
| `-i.bak` | edit file in place and create a backup |

## 32. Summary

```bash
sed 's/old/new/' file.txt                 # replace first occurrence on each line
sed 's/old/new/g' file.txt                # replace all occurrences on each line
sed 's|/old/path|/new/path|g' file.txt    # use another delimiter for paths

sed -n '3p' file.txt                      # print line 3
sed -n '2,5p' file.txt                    # print lines 2 to 5
sed -n '/pattern/p' file.txt              # print lines matching pattern

sed '3d' file.txt                         # delete line 3
sed '2,5d' file.txt                       # delete lines 2 to 5
sed '/pattern/d' file.txt                 # delete lines matching pattern

sed '/pattern/s/old/new/g' file.txt       # replace only on lines matching pattern
sed '/pattern/!s/old/new/g' file.txt      # replace only on lines not matching pattern

sed -E 's/([A-Za-z]+) ([A-Za-z]+)/\2 \1/' names.txt # use groups and backreferences
sed -E 's/[0-9]+/[&]/g' values.txt        # reuse matched text with &

sed '/pattern/i inserted line' file.txt   # insert line before pattern
sed '/pattern/a appended line' file.txt   # append line after pattern
sed '/pattern/c changed line' file.txt    # replace whole matching line

sed -e 's/a/b/g' -e 's/c/d/g' file.txt    # apply multiple commands
sed -f commands.sed file.txt              # read commands from a sed script

sed -i.bak 's/old/new/g' file.txt         # edit in place and keep backup
```
