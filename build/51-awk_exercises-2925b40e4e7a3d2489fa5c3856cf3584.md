# `awk` - Practical Examples

## Processing a simulation log

Create a log file:

```bash
cat > simulation.log
step 0 status OK energy 10.5
step 1 status OK energy 10.2
step 2 status WARNING energy 11.8
step 3 status OK energy 10.1
step 4 status FAILED energy 15.9
step 5 status OK energy 9.9
^D
```

Print step and energy:

```bash
awk '{print $2, $6}' simulation.log
```

Output:

```text
0 10.5
1 10.2
2 11.8
3 10.1
4 15.9
5 9.9
```

Print only rows where energy is larger than `11`:

```bash
awk '$6 > 11 {print $0}' simulation.log
```

Output:

```text
step 2 status WARNING energy 11.8
step 4 status FAILED energy 15.9
```

Compute average energy:

```bash
awk '{sum += $6; n += 1} END {print sum/n}' simulation.log
```

Output:

```text
11.4
```

Count status occurrences:

```bash
awk '{count[$4]++} END {for (s in count) print s, count[s]}' simulation.log
```

Possible output:

```text
OK 4
WARNING 1
FAILED 1
```

## Converting columns

Suppose the file contains a velocity in m/s:

```bash
cat > velocity.dat
# time velocity_m_s
0.0 1.2
0.1 1.4
0.2 1.5
0.3 1.7
^D
```

Convert velocity from m/s to cm/s:

```bash
awk '!/^#/ {print $1, 100*$2}' velocity.dat
```

Output:

```text
0.0 120
0.1 140
0.2 150
0.3 170
```

Add a header:

```bash
awk 'BEGIN {print "# time velocity_cm_s"} !/^#/ {print $1, 100*$2}' velocity.dat
```

Output:

```text
# time velocity_cm_s
0.0 120
0.1 140
0.2 150
0.3 170
```

Save to a new file:

```bash
awk 'BEGIN {print "# time velocity_cm_s"} !/^#/ {print $1, 100*$2}' velocity.dat > velocity_cm_s.dat
```

## Selecting a time interval

Using `measurements.dat`, select rows where time is between `0.1` and `0.3`:

```bash
awk '!/^#/ && $1 >= 0.1 && $1 <= 0.3 {print $0}' measurements.dat
```

Output:

```text
0.1  1.4  10.3
0.2  1.5  10.4
0.3  1.7  10.8
```

Print only time and pressure:

```bash
awk '!/^#/ && $1 >= 0.1 && $1 <= 0.3 {print $1, $3}' measurements.dat
```

Output:

```text
0.1 10.3
0.2 10.4
0.3 10.8
```

## Normalizing a column

Compute velocity divided by the maximum velocity.

First, find the maximum velocity:

```bash
awk '!/^#/ {if (n == 0 || $2 > max) max = $2; n++} END {print max}' measurements.dat
```

Output:

```text
1.7
```

To normalize in one `awk` command, we need two passes over the file.

```bash
awk '
    FNR == NR && !/^#/ {
        if (n == 0 || $2 > max) max = $2
        n++
        next
    }

    FNR != NR && !/^#/ {
        print $1, $2/max, $3
    }
' measurements.dat measurements.dat
```

Explanation:

- the file is passed twice;
- during the first pass, `awk` computes the maximum;
- during the second pass, `awk` prints normalized values.

This is more advanced, but useful for data processing.
