# Array Indexing: Fortran vs. C

In scientific computing and high-performance applications, **arrays are central data structures.** 
However, the way they are declared, accessed, and optimized can vary significantly between programming languages.

This lecture explores a key difference: Why multidimensional arrays are the norm in Fortran, while in C one-dimensional arrays are often preferred—even when the data is logically multi-dimensional.

## Fortran: Native Multidimensional Arrays

Fortran was designed with numerical computing in mind. Its array support is rich and natural:
```Fortran
real, dimension(10,10) :: A
A(3,7) = 42.0
```
Multidimensional arrays are a first-class concept in Fortran, and the language provides:
- Native syntax for multidimensional declarations
- Column-major storage layout (i.e., `A(i,j)` is stored with varying `i` fastest)
- Whole-array operations and slicing
- Compiler optimizations for cache locality and loop vectorization

Because of this, Fortran programmers use 2D, 3D, or even higher-dimensional arrays routinely without extra bookkeeping.

**Fortran compilers** are also very good at **optimizing loops** over these arrays—especially when the data access follows a contiguous memory pattern.

## C: Prefer 1D Arrays with Lexicographic Indexing

C supports multidimensional arrays syntactically:
```C
int A[10][10];
A[3][7] = 42;
```
But internally, **C stores arrays in row-major order:** `A[i][j]` is laid out with `j` varying fastest. And while the syntax is familiar, it becomes cumbersome in dynamic settings (e.g., when dimensions are only known at runtime).

More importantly, passing multidimensional arrays to functions or allocating them dynamically is tricky in C. For example, allocating a 2D array dynamically often requires a pointer-to-pointer and nested `malloc` calls, or complex casting.

Because of these complications, C programmers often flatten the array manually and use 1D arrays with lexicographic indexing:
```C
int *A = malloc(Nx * Ny * sizeof(int));
A[i * Ny + j] = 42;
```
This approach provides:
- Full control over memory layout
- Easier dynamic allocation
- Improved performance (if the memory access pattern is well-optimized)
- Compatibility with MPI and GPU code, where linear arrays are the norm
  

## Lexicographic Indexing Example (C)

Assume we want a 2D array `A(i,j)` of size `Nx` × `Ny`:
```C
int *A = malloc(Nx * Ny * sizeof(int));

for (int i = 0; i < Nx; i++) {
    for (int j = 0; j < Ny; j++) {
        A[i * Ny + j] = i + j;  // access as 1D
    }
}
```

> [!NOTE]
> - **Fortran** promotes the use of **multidimensional arrays** with natural syntax and high performance.
> - **C**, due to its lower-level nature, often requires programmers to **flatten multidimensional data** into 1D arrays and manage indexing manually.
> - **Lexicographic indexing** in C is not only a workaround — it is a **powerful technique** that ensures compatibility, flexibility, and control in high-performance code.

## Example: Lexicographic Indexing in 3D Arrays (C)

Suppose you want to represent a 3D array `A(i,j,k)` of size:
- `Nx` elements along the `i` (first) direction,
- `Ny` elements along the `j` (second) direction,
- `Nz` elements along the `k` (third) direction.

C stores multidimensional arrays in row-major order: the last index (`k`) varies fastest in memory.

To access `A[i][j][k]` in a 1D array, you compute its linear index as:
```C
index = i * (Ny * Nz) + j * Nz + k
```
This formula works because:
- Advancing 1 step in `i` jumps over an entire 2D (`Ny`×`Nz`) plane,
- Advancing 1 step in `j` jumps over one row of `Nz` elements,
- Advancing 1 step in `k` moves to the next element.

### Code Example

Here’s how you’d dynamically allocate and use a 3D array with lexicographic indexing in C:
```C
#include <stdio.h>
#include <stdlib.h>

int main() {
    int Nx = 4, Ny = 3, Nz = 2;

    // Allocate a flat array of size Nx * Ny * Nz
    float *A = malloc(Nx * Ny * Nz * sizeof(float));

    // Fill the array using lexicographic index
    for (int i = 0; i < Nx; i++) {
        for (int j = 0; j < Ny; j++) {
            for (int k = 0; k < Nz; k++) {
                int index = i * (Ny * Nz) + j * Nz + k;
                A[index] = (float)(i + j + k);  // Example value
            }
        }
    }

    // Print a few values
    for (int i = 0; i < Nx; i++) {
        for (int j = 0; j < Ny; j++) {
            for (int k = 0; k < Nz; k++) {
                int index = i * (Ny * Nz) + j * Nz + k;
                printf("A[%d][%d][%d] = %f\n", i, j, k, A[index]);
            }
        }
    }

    free(A);
    return 0;
}
```
Output (truncated for clarity)
```
A[0][0][0] = 0.000000
A[0][0][1] = 1.000000
A[0][1][0] = 1.000000
A[0][1][1] = 2.000000
...
A[3][2][1] = 6.000000
```
