# Strings in C

In a simulation, we use numbers for physical quantities and text for dataset
names, filenames, or model names. In C, this text is represented using
**strings**: sequences of characters ending with a special character, `'\0'`.

The following program stores a dataset name, prints it, changes one character,
copies the name, and compares the two strings.

## Complete C program

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char dataset[32] = "run_A";
    char saved_name[32];

    printf("Dataset: %s\n", dataset);
    printf("First character: %c\n", dataset[0]);
    printf("Length: %zu\n", strlen(dataset));
    printf("Array capacity: %zu bytes\n", sizeof(dataset));

    dataset[4] = 'B';
    printf("Updated dataset: %s\n", dataset);

    strcpy(saved_name, dataset);
    printf("Copy: %s\n", saved_name);

    if (strcmp(dataset, saved_name) == 0) {
        printf("The names are equal.\n");
    }

    return 0;
}
```

Save it as `strings.c`, then compile and run it:

```bash
gcc strings.c -o strings
./strings
```

Output:

```text
Dataset: run_A
First character: r
Length: 5
Array capacity: 32 bytes
Updated dataset: run_B
Copy: run_B
The names are equal.
```

## A string is a character array with a terminator

The declaration

```c
char dataset[32] = "run_A";
```

creates an array of 32 characters. Its first six elements are:

| Index | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| Content | `'r'` | `'u'` | `'n'` | `'_'` | `'A'` | `'\0'` |

The character `'\0'` marks the end of the string. It has numeric value zero
and is different from the digit `'0'`. Functions that operate on strings use
this terminator to find where the text ends.

The literal `"run_A"` provides five text characters plus the terminator.
It therefore needs at least **six array elements**. In our 32-element array,
the remaining elements are also initialized to zero.

You can let the compiler determine the size:

```c
char name[] = "run_A";
```

This array has six elements, leaving no extra capacity for a longer name.

## Characters, strings, and printing

Single quotes denote one character, as in `'A'`. Double quotes denote a string
literal, as in `"run_A"`.

Use `%c` with `printf` for a single character and `%s` for an entire string:

```c
printf("%c\n", dataset[0]);
printf("%s\n", dataset);
```

Printing with `%s` requires a valid null-terminated string. An uninitialized
character array is not ready to be printed as a string.

## Length and capacity are different

The functions in `<string.h>` operate on strings. In particular:

- `strlen(dataset)` returns the number of bytes before `'\0'`: 5 in this example.
- `sizeof(dataset)` returns the size of the array: 32 bytes.

For the simple text used here, each character occupies one byte. The terminator
counts toward storage capacity but is not included in `strlen`.

> [!NOTE]
> **Why `%zu` instead of `%d`?**
>
> `sizeof` and `strlen` return a value of type `size_t`, an unsigned integer
> type used for sizes and lengths. In `printf`, `%zu` is the format specifier
> for this type: `z` selects `size_t` and `u` requests unsigned decimal output.
> `%d` expects an `int`, so using it directly with a `size_t` value is a type
> mismatch and can produce undefined behavior.

The capacity calculation with `sizeof` applies where `dataset` is an array;
an array parameter inside a function is instead treated as a pointer.

## Changing and copying a string

We change one character with:

```c
dataset[4] = 'B';
```

The terminator remains at index 5, so the resulting string is `"run_B"`.
Always keep the terminator inside the array.

C does not allow assigning a new string to an existing array with
`dataset = "run_B"`. To copy text into an array, use `strcpy`:

```c
strcpy(saved_name, dataset);
```

The first argument is the destination and the second is the source.
The copy includes the terminating `'\0'`. The destination must have room for
`strlen(source) + 1` characters. Here both arrays have 32 elements and the
source contains only five text characters, so the copy fits.

`strcpy` does not check destination capacity. Use it only when you know the
destination is large enough.

## Copying characters versus storing an address

With `strcpy(saved_name, dataset)`, we copied characters into an existing
array. The destination has its own storage: changing its characters does
not change the source string.

You may also encounter a declaration that looks like another way to store
text:

```c
char *model = "Lennard-Jones";
```

To understand when this is useful, we need to distinguish **copying the
characters** from **storing their address**.

Here, `model` is a pointer: it stores the address of the first character of
`"Lennard-Jones"`. The declaration does not create a separate character array
that we can edit. The characters belong to the **string literal**, and C does
not allow us to modify a string literal.

Even though the declaration uses `char *`, writing `model[0] = 'l';`
would have **undefined behavior** and could crash the program. The pointer's
type does not make the literal writable.

> [!NOTE]
> **Why prefer `const char *` for a string literal?**
>
> A clearer declaration is:
> ```c
> const char *model = "Lennard-Jones";
> ```
> `const` tells the compiler that the characters must not be changed through
> this pointer. It can then diagnose an attempted assignment such as
> `model[0] = 'l';`. The literal was already non-modifiable; `const` makes
> that restriction explicit in the pointer's type.
>
> You can still assign `model = "Ising";`: this changes where the pointer
> points, rather than modifying the characters. We use `const char *` for
> pointers to string literals in the examples that follow.

Compare this with:

```c
char model_name[] = "Lennard-Jones";
model_name[0] = 'l';
printf("%s\n", model_name);  // prints lennard-Jones
```

This declaration creates an array and initializes it with a **copy** of the
literal's characters, including the terminating `\0`. The array belongs to
our program as writable storage, so changing `model_name[0]` is allowed.

A pointer can also be redirected to another literal:

```c
const char *model = "Lennard-Jones";
model = "Ising";
```

The assignment changes the address stored in `model`; it does not change the
characters in either literal. With an array, changing the text means changing
or copying its characters within the available capacity, as shown above.

## Comparing strings

To compare text, use `strcmp`:

```c
if (strcmp(dataset, saved_name) == 0) {
    printf("The names are equal.\n");
}
```

A return value of **zero** means the contents are equal. A negative or positive
result indicates that the first string comes before or after the second in
the comparison order; the result is not necessarily -1 or 1.

The operator `==` on string pointers compares addresses, so it does not tell
you whether two strings contain the same text.

## Reading a word into a string

To read a dataset name from standard input, use a width limit:

```c
char dataset[32];

if (scanf("%31s", dataset) == 1) {
    printf("Dataset: %s\n", dataset);
}
```

`%31s` reads at most 31 characters, leaving one element for `'\0'`.
Pass `dataset` without `&`: the array converts to a pointer to its first character.

The same rule applies to `fscanf` when reading a word from a file.
The `%s` conversion stops at whitespace; it does not read a whole sentence.
To read a line containing spaces, the standard library provides `fgets`.
