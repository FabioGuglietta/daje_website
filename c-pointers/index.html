Call by Value, Call by Refrence and Pointers

Call by Value¶

We now want to write a simple function, called modify_value(a, b, c), that takes as input three integer parameters and performs the following operations: a = a + c and b = b - c.

#include <stdio.h>

// Function using pass-by-value
void modify_value(int a, int b, int c) {
    a = a + c;
    b = b - c;
}

int main() {
    int a = 10, b = 20;

    printf("Before modify_value: a = %d, b = %d\n", a, b);
    modify_value(a, b, 5);
    printf("After modify_value:  a = %d, b = %d\n\n", a, b);

    return 0;
}

The output of this code is:

Before modify_value: a = 10, b = 20
After modify_value:  a = 10, b = 20

When this program is executed, the output shows that the values of a and b remain unchanged after the call to modify_value. This behavior stems from the fact that C uses pass-by-value for function arguments by default. When the function modify_value(a, b, 5) is called, the values of a, b, and c are copied into new local variables within the function. Any operations performed inside modify_value —- such as modifying a and b —- affect only the local copies, not the original variables declared in main. As a result, once the function returns, those modifications are discarded, and the original variables retain their initial values.

Note

The function works with copies of the inputs, NOT with the inputs themselves.

So, how can we solve this issue?

Call by Reference¶

To answer that, we need to take a step back and consider what actually happens when a variable is declared in a program.

Behind the scenes, each variable is stored in a specific location in the computer’s memory. This location is identified by a memory address, which is simply a numerical label assigned to a slot in memory, like for example 0x7ffe5367e044. You can think of it like the street address of a house: just as a house can be uniquely found by its address, a variable’s contents can be retrieved (or modified) by knowing its memory location.

When we call a function in C and pass it a variable, what we’re actually doing by default is giving the function a copy of that variable’s value. This is why any modification inside the function doesn’t affect the original: the function is working on its own local copy, which disappears when the function ends.

But what if, instead of passing a copy, we pass the address of the variable? In this way, the function doesn’t operate on a temporary local value -— it accesses the original variable, directly in memory. This approach allows the function to modify the caller’s data and is known as passing by reference.

By passing a variable’s address to a function, we effectively say: “Here is where the original value lives —- feel free to go there and make changes.” This opens the door to more powerful and flexible programming patterns, and is essential in many areas such as numerical computation, memory management, and system-level programming.

Note

Call-by-Value: A copy of the variable’s value is passed to the function. Changes made inside the function do not affect the original variable.

Call-by-Reference: The address of the variable is passed to the function. The function can access and modify the original variable.

Therefore, it would be great if we could modify the function modify_value(int a, int b, int c) so that the first two arguments are not just the values of variables a and b passed from main, but rather their memory addresses. In pseudocode, this would look something like:

modify_value( [address of] int a, [address of] int b, int c) {
    [value stored at [address of]] a = [value stored at [address of]] a + c;
    [value stored at [address of]] b = [value stored at [address of]] b - c;
}

In other words, the goal is to give the function modify_value the [address of] the variables, so it can directly modify the [value stored at] those addresses.

For example, if [address of] a = 221B Baker Street, then the function travels to that location, inspects the contents of the house (i.e., the value stored in memory), and updates it accordingly. The same goes for variable b.

Now, how do we achieve this in C? How can we access the address of a variable?¶

This is done using the ampersand operator &, which corresponds to the pseud-code operation [address of]. By writing &a or &b, we retrieve the memory addresses of variables a and b, which can then be passed to a function.

And now, what corresponds to the pseudo-code operation [value stored at [address of] a]? This is done using the asterisk operator *, also known as the dereference operator. When applied to a memory address, * allows us to access or modify the actual value stored at that memory location.

Let’s look at this short example:

#include <stdio.h>

int main() {
    int a = 42;

    printf("Value of a: %d\n", a);
    printf("Address of a: %p\n", &a);
    printf("Value stored at address of a: %d\n", *(&a));

    return 0;
}

whose output is

Value of a: 42  
Address of a: 0x7ffee74c6a2c  
Value stored at address of a: 42
Warning

The %p format specifier in printf is used to print a memory address (a pointer value). It displays the address of a variable in hexadecimal form, showing where that variable is stored in memory.

Note

  • Use & to get the address of a variable.

  • Use * to access (or modify) the value at the address stored in a pointer.

Pointers¶

Let’s quickly recap what we’ve seen so far: every variable is stored somewhere in the computer’s memory, and each location has a unique memory address. We can access this address using the & operator, and we can read or write the value stored at an address using the * operator.

This leads to an interesting idea: what if we had a variable whose job is to store a memory address? For example, a “memory-address” kind variable whose job is to store the address of a variable (not its value!).

For example, in pseudocode:

int a = 42;
address p = &a;
print("Value of a: ", a, " - Address of a: ", &a)
print("Value of p: ", p, "Value stored at p: ", *p)

and the output is:

Value of a: 42 - Address of a: 0x7ffee74c6a2c  
Value of p: 0x7ffee74c6a2c - Value stored at p: 42

Well, in C, the variable p is called pointer. A pointer is a variable that holds the address of another variable. In this way, the pointer points to a specific location in memory, and we can use it to access or modify the data stored at that location.

The above pseudo code, in C, would read:

#include <stdio.h>

int main() {
    int a = 42;
    (int *) p = &a;  // Declare a pointer to int and store the address of a

    printf("Value of a: %d - Address of a: %p\n", a, (void*)&a);
    printf("Value of p (i.e., address of a): %p - Value stored at p: %d\n", (void*)p, *p);

    return 0;
}

The data type tells the compiler what type of data the variable will contain whose address we are going to store. In our last example, p is a pointer to an int.

Warning

This doesn’t mean that p will store an int value. A pointer to an integer (like p) can only store the address of variables of type int.

The following is an example of a function that has as arguments the memory address of some variables:

#include <stdio.h>

void function(int *a, float *b){
  *a = (int) *b;
  *b -= (float) *a;
}

int main() {
    int a = 0;
    float b = 42.3;

    function(&a, &b);
   
    printf("Value of a: %d \n", a);
    printf("Value of b: %f \n", b);

    return 0;
}

The ouptut is:

Value of a: 42 
Value of b: 0.299999
Warning

Why 0.3 Isn’t Exactly 0.3 in a Computer¶

When you ask a computer to store the number 0.3, it does its best — but it can’t.
Computers store real numbers in binary, not decimal.
A binary fraction uses powers of two:

x=b0×20+b1×2−1+b2×2−2+b3×2−3+…x = b_0 \times 2^0 + b_1 \times 2^{-1} + b_2 \times 2^{-2} + b_3 \times 2^{-3} + \dotsx=b0​×20+b1​×2−1+b2​×2−2+b3​×2−3+…
(1)

Each bib_ibi​ is either 0 or 1.

Some numbers, like 0.5=1/20.5 = 1/20.5=1/2, have an exact binary form. But others, like 0.1 or 0.3, do not. Their binary expansions are infinitely repeating:

0.310=0.01001100110011001100…0.3_{10} = 0.01001100110011001100\dots0.310​=0.01001100110011001100…

Since computer memory is finite, this expansion must be truncated and rounded.

Understanding * and &¶

When working with pointers, two key operators in C are the asterisk (*) and the ampersand (&). They play crucial roles in accessing and manipulating memory addresses.

The * operator is used to dereference a pointer, which means accessing the value stored at the memory address the pointer holds.

int x = 10;
int *ptr = &x;    // ptr holds the address of x
printf("%d\n", *ptr);  // Dereferencing ptr gives the value of x (10)

In this example, ptr stores the address of x, *ptr accesses the value at that address (which is 10 in this case). Dereferencing allows you to manipulate or read the value stored at the location the pointer is pointing to.

The & operator is used to get the memory address of a variable.

Warning

& gives the address of the variable, not its value!

int x = 10;
int *ptr = &x;  // &x gives the address of x, which is stored in ptr

In the last example, &x returns the memory address where the variable x is stored. This address is assigned to ptr, making ptr a pointer to x.

Warning

Note that the asterisk * is used both for declaring the pointer and for dereferencing it:

int var = 42;
int *ptr; // The * is used to declare a pointer 
ptr = &var;
printf("Var = %d", *ptr); // The * is used to dereference the pointer (i.e., to show the value stored at address p = &var)

Wild Pointers¶

Those pointers that do not point to any address are called wild:

char *alphabetAddress; //Wild pointer
char alphabet = "a";
alphabetAddress = &alphabet; //No more wild
Tip

To ensure that we don’t have a wild pointer, we can initialize a pointer with a NULL value, making it a null pointer:

char *alphabetAddress = NULL;

Pointer Arithmetic¶

Pointer arithmetic means performing arithmetic operations (addition or subtraction) on a pointer. However, you can only add or subtract integers to/from pointers:

int *ptr;
ptr += 1;    // Valid
ptr -= 2;    // Valid
ptr *= 3;    // Invalid

When you add 1 to a pointer, you’re actually adding the size of the type it points to. That is, ptr + 1 moves the pointer forward by sizeof(*ptr) bytes.

Warning

When you add (or subtract) an integer (say n) to a pointer, you’re NOT actually adding (or subtracting) n bytes to the pointer’s value. Instead, you are adding (or subtracting) n times the size in bytes of the data type of the variable being pointed to.

int a = 5;
int *ptr = &a;            // Assume the address is 1000
int newAddress = ptr + 3; // It is equal to: ptr + 3*sizeof(int) = 1000 + 3*4 = 1012

Let’s look at the follwing code:

#include <stdio.h>

int main(){
  int arr0D    = 42;
  int  *p0     = &arr0D;
 
  printf("-------------------------------\n");
  printf("0D array (variable) and pointer\n");
  printf("-------------------------------\n");
  printf("Number of element of arr0D = %d \n",  sizeof(arr0D)/sizeof(int));
  printf("Sizeof(arr0D) = %d Bytes\n\n",  sizeof(arr0D));
  printf("arr0D   = %d ; &arr0D = %d\n",     arr0D    , &arr0D);
  printf("*p0     = %d ; p0     = %d\n\n",   *p0      , p0    );
  printf("*(p0+1) = %d ; p0+1   = %d\n\n",   *(p0+1)  , p0+1    );

whose output is:

-------------------------------
0D array (variable) and pointer
-------------------------------
Number of element of arr0D = 1 
Sizeof(arr0D) = 4 Bytes

arr0D   = 42 ; &arr0D = 1830580912
*p0     = 42 ; p0     = 1830580912

*(p0+1) = 1837085824 ; p0+1   = 1830580916

We immediately see that, since p0 = &arr0D, it means that p0 is storing the address of arr0D. To obtain the corresponding value at address &arr0D, we must dereference p0 (i.e., *p0). If we then add 1 to p0, we obtain the memory address stored at the same address of &arr0D (i.e., 1830580912) PLUS 4 Bytes (i.e., 1830580916). If we dereference *(p0+1), we obtain some trash value.

Memory Allocation¶

A pointer in C can either point to an existing variable, or to memory that you allocate at runtime using malloc.

Declaring a pointer like this:

int *p;

only creates the pointer variable — a small space in memory to hold an address. But at this point, p doesn’t point to any valid memory. It contains an undefined (garbage) value.

Trying to use *p at this stage — for example:

*p = 42;

will likely cause a crash (segmentation fault), because you’re trying to write to a memory location you don’t own.

To safely store a value through a pointer, you must first assign it a valid memory address. You can do this in one of two ways:

Option 1: Point to an existing variable¶

int x = 10;
int *p = &x;
*p = 42;  // modifies x

Option 2: Allocate memory dynamically with malloc()¶

int *p = malloc(sizeof(int));
*p = 42;  // now valid

This second option asks the operating system to reserve space for one int on the heap. Now p points to valid, writable memory — and using *p is safe.

Note

A pointer only holds an address — it doesn’t come with memory to store a value. You must give it a valid address before dereferencing it.

Example: Allocate memory for one int¶

#include <stdlib.h>
#include <stdio.h>

int main() {
    int *p = (int *)malloc(sizeof(int));
    *p = 123;

    printf("Value at p: %d\n", *p);
    free(p);
    return 0;
}

The malloc function reserves memory of the requested size (here, sizeof(int)) and returns a pointer to that memory. You can then use pointer arithmetic to navigate the memory region if it’s large enough.

Example: Allocate memory for two floats¶

#include <stdlib.h>
#include <stdio.h>

int main() {
    float *q = (float *)malloc(2 * sizeof(float));
    *(q + 0) = 1.5;
    *(q + 1) = 2.5;

    printf("First float:  %f\n", *(q));
    printf("Second float: %f\n", *(q + 1));

    free(q);
    return 0;
}

This sets the stage for managing multiple elements via a single pointer — the basis of arrays.

Pointers as Views into Memory¶

A pointer lets you access a block of memory. Depending on how much memory you allocate with malloc, the same pointer can be used to read or write multiple values, using arithmetic.

Think of it like a cursor into a sequence of values:

float *p = malloc(3 * sizeof(float));
*p       = 0.1;       // First value
*(p + 1) = 0.2;       // Second value
*(p + 2) = 0.3;       // Third value

Even though we haven’t introduced arrays yet, this pattern shows how a single pointer can traverse memory as if it were a sequence.

Pointer Arithmetic and Garbage Values¶

If you move the pointer beyond the allocated memory and try to dereference it, the result is undefined behavior. For instance:

int x = 5;
int *p = &x;
printf("%d\n", *(p + 1));  // Undefined! Points to unknown memory

This may print garbage or crash your program.

Warning

Always make sure that any arithmetic stays within a valid, allocated region.

Note

  • Pointer arithmetic moves in units of the size of the type it points to.

  • malloc lets you allocate memory at runtime; pointers can be used to access and navigate that memory.

  • Misusing pointer arithmetic (e.g., accessing outside valid memory) leads to undefined behavior.

Releasing Memory with free()¶

When you allocate memory using malloc, that memory stays reserved until you explicitly release it using the free() function. If you forget to call free, the memory remains occupied even after it’s no longer needed — this is called a memory leak.

int *p = malloc(sizeof(int));
*p = 100;
free(p);  // releases the memory back to the system

Using free properly ensures your program doesn’t waste memory or crash unexpectedly over time.

Warning

Always free memory you’ve malloc’d, once you’re done using it.

Some applications of pointers¶

Pointers to function¶

In C, not only can you create pointers to variables, but you can also create pointers to functions. This feature allows for more flexibility in programming, especially when you need to pass functions as arguments to other functions, or when you want to select a specific function at runtime.

A function pointer is a variable that stores the address of a function. Indeed, every variable and instruction in a program has a memory address. Similarly, a function’s entry point has its own memory address, which is linked to the function’s name.

Just like any other pointer, you can dereference a function pointer to call the function it points to.

Below is an example that shows how function pointers can be used. In this case, we have two functions: add and subtract. We then use a function pointer to select which function to call based on a condition.

#include <stdio.h>

// Functions
int add(int a, int b) {
    return a + b;
}

int subtract(int a, int b) {
    return a - b;
}

int main() {
    int (*operation)(int, int);  // Declare a function pointer

    int x = 10, y = 5;
    char op;

    printf("Enter operation (+ or -): ");
    scanf(" %c", &op);

    // Assign function to pointer based on user input
    if (op == '+') {
        operation = add;
    } else if (op == '-') {
        operation = subtract;
    } else {
        printf("Invalid operation\n");
        return 1;
    }

    // Call the function via pointer
    int result = operation(x, y);
    printf("Result: %d\n", result);

    return 0;
}

Explanation:

  • The line int (*operation)(int, int); declares a pointer to a function that takes two int arguments and returns an int.

  • Function names like add or subtract can be assigned directly to a function pointer.

  • You can call the function using operation(x, y) or (*operation)(x, y) — both are valid.

Note

A function pointer behaves like any other pointer: it stores an address — but in this case, the address points to a **block of executable code **(i.e., a function). This allows for elegant and flexible programming patterns in C.

Pointers to pointer¶

In C, the ** symbol is used when you are dealing with pointers to pointers. This means you have a pointer that points to another pointer, which in turn points to some data. It’s often used in more complex scenarios such as dynamic memory allocation for multi-dimensional arrays, handling arrays of strings (array of character pointers), or passing pointers by reference to functions.

int x = 5;
int *ptr = &x;   // ptr is a pointer to x (an int)
int **ptr2 = &ptr; // ptr2 is a pointer to ptr (a pointer to int)

printf("%d\n", **ptr2);  // Dereferencing twice gives the value of x (5)

In this example:

How it Works:

  • ptr is a pointer to x and it stores the address of the integer x.

  • ptr2 is a pointer to ptr, so it stores the address of the pointer ptr.

  • When you dereference ptr2 once (i.e., *ptr2), you get the value of ptr, which is the address of x.

  • When you dereference it twice (i.e., **ptr2), you get the value stored in x.

A typical example is given by the following:

void modifyPointer(int **ptr) {
    static int y = 100;
    *ptr = &y;  // Modify the pointer itself to point to y
}

int main() {
    int x = 10;
    int *p = &x;
    modifyPointer(&p);  // Pass the address of p (pointer to pointer)
    printf("%d\n", *p); // Outputs 100, since p now points to y
}

Example: Using a Pointer to a Pointer with malloc¶

To dynamically allocate memory for a pointer inside a function, you need to pass a pointer to that pointer. This allows the function to modify the original pointer’s value (i.e., set it to point to newly allocated memory).

#include <stdio.h>
#include <stdlib.h>

void allocateInt(int **p) {
    *p = malloc(sizeof(int));
    if (*p == NULL) {
        printf("Memory allocation failed\n");
        exit(1);
    }
    **p = 42;  // set value after allocation
}

int main() {
    int *ptr = NULL;

    allocateInt(&ptr);  // pass address of the pointer
    printf("Value: %d\n", *ptr);

    free(ptr);  // always free dynamically allocated memory
    return 0;
}
