Exercise — Analysis of a velocity time series

A numerical simulation produces a file containing measurements of the velocity (v(t)) at different times.

The input file contains exactly 100 data points. Each line contains two values:

time    velocity

For example:

0.0   1.24
0.1   1.31
0.2   1.18
...

The first column contains the time (t), while the second column contains the velocity (v(t)).

The input file is provided as input.dat.

Program execution¶

Write a C program that is executed from the command line as

./analyze input.dat output.dat

where:

  • argv[0] is the program name;

  • argv[1] is the input file name;

  • argv[2] is the output file name.

The program must check that the correct number of command-line arguments has been provided.

Tasks¶

  1. Open the input file specified by argv[1].

  2. Check that the file was opened successfully.

  3. Read the 100 pairs (ti,vi)(t_i, v_i)(ti​,vi​) and store them in two arrays:

double time[100];
double velocity[100];

  2. Compute the standard deviation σv=1N∑i=0N−1(vi−vˉ)2\sigma_v = \sqrt{ \frac{1}{N} \sum_{i=0}^{N-1} (v_i-\bar{v})^2 }σv​=N1​∑i=0N−1​(vi​−vˉ)2​.

  3. Find the minimum and maximum velocity.

  4. Count how many velocity values satisfy vi>vˉv_i > \bar{v}vi​>vˉ.

  5. Open the output file specified by argv[2].

  6. Write the following information to the output file:

Number of measurements: 100

Mean velocity:     ...
Std. deviation:    ...
Minimum velocity:  ...
Maximum velocity:  ...
Values above mean: ...

  1. After the summary, write all data points in the following format:

  1. Close both files using fclose().

Solution¶

Solution in C
 #include <stdio.h>
 #include <stdlib.h>
 #include <math.h>
 
 #define N 100
 
 int main(int argc, char **argv)
 {
     FILE *fin;
     FILE *fout;
 
     double time[N];
     double velocity[N];
 
     /* Check command-line arguments */
     if (argc != 3) {
         printf("Usage: %s input_file output_file\n", argv[0]);
         return 1;
     }
 
     /* Open input file */
     fin = fopen(argv[1], "r");
 
     if (fin == NULL) {
         printf("Error: cannot open input file %s\n", argv[1]);
         return 1;
     }
 
     /* Read the 100 data points */
     for (int i = 0; i < N; i++) {
         fscanf(fin, "%lf %lf", &time[i], &velocity[i]);
     }
 
     fclose(fin);
 
     /* Compute mean velocity */
     double sum = 0.0;
 
     for (int i = 0; i < N; i++) {
         sum += velocity[i];
     }
 
     double mean = sum / N;
 
     /* Compute standard deviation */
     double sum2 = 0.0;
 
     for (int i = 0; i < N; i++) {
         double diff = velocity[i] - mean;
         sum2 += diff * diff;
     }
 
     double std_dev = sqrt(sum2 / N);
 
     /* Find minimum and maximum */
     double min = velocity[0];
     double max = velocity[0];
 
     for (int i = 1; i < N; i++) {
 
         if (velocity[i] < min) {
             min = velocity[i];
         }
 
         if (velocity[i] > max) {
             max = velocity[i];
         }
     }
 
     /* Count values above the mean */
     int above_mean = 0;
 
     for (int i = 0; i < N; i++) {
 
         if (velocity[i] > mean) {
             above_mean++;
         }
     }
 
     /* Open output file */
     fout = fopen(argv[2], "w");
 
     if (fout == NULL) {
         printf("Error: cannot open output file %s\n", argv[2]);
         return 1;
     }
 
     /* Write summary */
     fprintf(fout, "Number of measurements: %d\n\n", N);
 
     fprintf(fout, "Mean velocity:     %f\n", mean);
     fprintf(fout, "Std. deviation:    %f\n", std_dev);
     fprintf(fout, "Minimum velocity:  %f\n", min);
     fprintf(fout, "Maximum velocity:  %f\n", max);
     fprintf(fout, "Values above mean: %d\n", above_mean);
 
     /* Write data and deviation from the mean */
     fprintf(fout, "\n");
     fprintf(fout, "# time        velocity        deviation_from_mean\n");
 
     for (int i = 0; i < N; i++) {
 
         fprintf(fout, "%f    %f    %f\n",
                 time[i],
                 velocity[i],
                 velocity[i] - mean);
     }
 
     fclose(fout);
 
     return 0;
 }
