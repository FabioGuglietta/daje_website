Physics Background

Objective: Simulate the motion of two bodies interacting via Newtonian gravity in 2D. Structure your code using modules and define a Body type/class that stores each particle’s state and provides methods for updating it.

Physics Background¶

Each body is characterized by:

  • Position: (x,y)(x, y)(x,y)

  • Velocity: (vx,vy)(v_x, v_y)(vx​,vy​)

  • Mass: mmm

The force between two bodies is given by Newton’s law of universal gravitation:

(1)

Use a simple Euler integration to update positions and velocities over time:

a⃗=F⃗m ,\vec{a} = \frac{\vec{F}}{m}\ ,a=mF​ ,

v⃗(t+Δt)=v⃗(t)+a⃗Δt ,\vec{v}(t + \Delta t) = \vec{v}(t) + \vec{a} \Delta t\ ,v(t+Δt)=v(t)+aΔt ,
(3)
x⃗(t+Δt)=x⃗(t)+v⃗(t)Δt\vec{x}(t + \Delta t) = \vec{x}(t) + \vec{v}(t) \Delta tx(t+Δt)=x(t)+v(t)Δt

Requirements¶

  1. Define a Body type/class:

  • Mass

  • Position (2D)

  • Velocity (2D)

C: use struct Fortran: use class with type

  1. Write a module gravity that provides:

  • compute_force(b1, b2, fx, fy) — computes the gravitational force on b1 due to b2

  • update_body(b, fx, fy, dt) — applies the force to update b using Euler’s method

  • print_body(b) — prints the body state

  1. In the main program:

  • Define two bodies (e.g., Sun and Earth-like)

  • Simulate motion for 1000 steps with dt = 0.01

  • Print or store their trajectories
