sed

sed means stream editor.

It is a command-line tool used to process text line by line. It reads input, applies editing commands, and writes the result to standard output.

For example:

sed 's/old/new/' file.txt

means:

read file.txt, replace old with new, print the result

By default, sed does not modify the original file. It prints the modified text to the screen.

This makes sed useful for:

  • replacing words or patterns;

  • deleting lines;

  • printing selected lines;

  • editing configuration files;

  • modifying many files automatically;

  • processing text inside shell scripts;

  • building pipelines with other Unix commands.

The general syntax of sed is:

sed [options] 'command' file

where:

  • command is the editing instruction;

  • file is the input file;

  • [options] are optional flags that modify the behavior of sed.

For example:

sed 's/cow/goat/' file.txt

Here:

  • s/cow/goat/ is the sed command;

  • s means substitute;

  • cow is the text to search for;

  • goat is the replacement text;

  • file.txt is the input file.

Note

If no file is given, sed reads from standard input:

echo "The cow is here" | sed 's/cow/goat/'

Output:

The goat is here

Let’s create an example file:

cat > animals.txt
The cow is in the field.
The cow is a calm animal.
The dog is in the garden.
The cows are eating grass.
A cow can produce milk.
^D

Inspect it:

cat animals.txt

Output:

The cow is in the field.
The cow is a calm animal.
The dog is in the garden.
The cows are eating grass.
A cow can produce milk.

We will use this file in the next examples.

Basic substitution¶

The most common sed command is substitution:

sed 's/old/new/' file.txt

The letter s means substitute.

Example:

sed 's/cow/goat/' animals.txt

Output:

The goat is in the field.
The goat is a calm animal.
The dog is in the garden.
The goats are eating grass.
A goat can produce milk.
Important

By default, sed replaces only the first occurrence of the pattern on each line.

Replacing all occurrences on a line¶

Create another file:

cat > repeated.txt
cow cow cow
dog cow dog
cow dog cow
^D

Run:

sed 's/cow/goat/' repeated.txt

Output:

goat cow cow
dog goat dog
goat dog cow

Only the first cow on each line is replaced.

To replace all occurrences on each line, add g:

sed 's/cow/goat/g' repeated.txt

Output:

goat goat goat
dog goat dog
goat dog goat

The g means global, but only globally on each line.

Saving the result to another file¶

By default, sed prints the modified text to the terminal.

To save the result to a file, use redirection:

sed 's/cow/goat/g' animals.txt > animals_modified.txt

The original file is unchanged.

Tip

This is the safest way to use sed while learning it.

Editing files in place with sed -i¶

To modify the original file directly, use the option -i.

On Linux:

sed -i 's/cow/goat/g' animals.txt

On macOS:

sed -i '' 's/cow/goat/g' animals.txt

The difference is important: macOS sed requires an argument after -i, even if it is an empty string.

Warning

Be careful with sed -i.

It modifies the file directly. If the command is wrong, the original file may be damaged.

A safer workflow is:

sed 's/old/new/g' file.txt > new_file.txt

Then inspect new_file.txt before replacing the original file.

Tip

A safer version creates a backup:

sed -i.bak 's/cow/goat/g' animals.txt

This modifies animals.txt and saves the old version as:

animals.txt.bak

On macOS, the same syntax also works.

Choosing another delimiter¶

The substitution command usually uses / as a delimiter:

sed 's/old/new/' file.txt

However, this becomes inconvenient when the text contains /.

Suppose you have a file paths.txt and you want to substitute this path:

/home/m.sega/data

with this:

/scratch/m.sega/data

The sed command will be:

sed 's/\/home\/m.sega\/data/\/scratch\/m.sega\/data/' paths.txt

This is hard to read because every / inside the path must be escaped using \.

sed allows other delimiters:

sed 's#/home/m.sega/data#/scratch/m.sega/data#' paths.txt

or:

sed 's|/home/m.sega/data|/scratch/m.sega/data|' paths.txt

These are equivalent and much clearer.

Example:

cat > paths.txt
/home/m.sega/data/input.dat
/home/m.sega/data/output.dat
^D

Run:

sed 's|/home/m.sega/data|/scratch/m.sega/data|' paths.txt

Output:

/scratch/m.sega/data/input.dat
/scratch/m.sega/data/output.dat

Replacing only specific occurrences¶

By default:

sed 's/cow/goat/' file.txt

replaces the first occurrence on each line.

With g:

sed 's/cow/goat/g' file.txt

it replaces all occurrences on each line.

You can also replace only the second occurrence:

sed 's/cow/goat/2' repeated.txt

Example input:

cow cow cow
dog cow dog
cow dog cow

Output:

cow goat cow
dog cow dog
cow dog goat

Only lines with at least two matches are changed.

Case-sensitive matching¶

By default, sed is case-sensitive.

Create a file:

cat > case.txt
Cow
cow
COW
cOw
^D

Run:

sed 's/cow/goat/' case.txt

Output:

Cow
goat
COW
cOw

Only lowercase cow is replaced.

With GNU sed, you can use I for case-insensitive matching:

sed 's/cow/goat/I' case.txt

Output:

goat
goat
goat
goat
Note

The I flag is supported by GNU sed, common on Linux.

It may not be portable to all sed implementations.

A more portable solution is to use a regular expression:

sed 's/[cC][oO][wW]/goat/' case.txt

Deleting lines¶

The command d deletes lines.

Create a file:

cat > log.txt
INFO starting simulation
INFO reading input
WARNING time step is large
INFO running
ERROR simulation failed
INFO finished
^D

Delete lines containing WARNING:

sed '/WARNING/d' log.txt

Output:

INFO starting simulation
INFO reading input
INFO running
ERROR simulation failed
INFO finished

Delete lines containing ERROR:

sed '/ERROR/d' log.txt

Delete both WARNING and ERROR lines:

sed '/WARNING/d; /ERROR/d' log.txt

or:

sed -e '/WARNING/d' -e '/ERROR/d' log.txt
Note

The option -e introduces one sed editing command. It is especially useful when we want to apply several sed commands in a single call.

Line addresses¶

Many sed commands can be restricted to specific lines.

The general form is:

sed 'address command' file

Examples:

sed '3d' file.txt

deletes line 3.

sed '2,5d' file.txt

deletes lines 2 to 5.

sed '1,3p' file.txt

prints lines 1 to 3, but because automatic printing is enabled, this duplicates those lines.

To print only lines 1 to 3:

sed -n '1,3p' file.txt

Useful address forms:

3        line 3
2,5      lines from 2 to 5
/pat/    lines matching pattern
$        last line
1,$      from first to last line

Examples:

sed -n '$p' log.txt

prints the last line.

sed '$d' log.txt

deletes the last line.

sed '1d' log.txt

deletes the first line.

sed '1,2d' log.txt

deletes the first two lines.

Applying substitutions only to selected lines¶

You can combine addresses and substitutions.

Replace INFO with MESSAGE only on line 1:

sed '1s/INFO/MESSAGE/' log.txt

Replace INFO with MESSAGE only between lines 1 and 3:

sed '1,3s/INFO/MESSAGE/' log.txt

Replace INFO with MESSAGE only on lines containing starting:

sed '/starting/s/INFO/MESSAGE/' log.txt

Replace INFO with MESSAGE on all lines except those containing ERROR:

sed '/ERROR/!s/INFO/MESSAGE/' log.txt

Here ! means not.

So:

/ERROR/!s/INFO/MESSAGE/

means:

on lines that do not match ERROR, replace INFO with MESSAGE

Regular expressions in sed¶

sed uses regular expressions to match patterns inside text.

A regular expression is a compact language for describing text patterns: digits, letters, line beginnings, line endings, repetitions, alternatives, and more.

Regular expressions are explained in detail in a dedicated lecture. Here we only report the most common patterns needed to understand typical sed commands.

For the examples below, suppose we have the file:

cat > numbers.txt
step 1
step 12
step 123
time 0.01
time 10.5
value abc
^D
GoalPatternExample commandMeaning
Match a digit[0-9]sed -n '/[0-9]/p' numbers.txtPrint lines containing at least one digit
Match a lowercase letter[a-z]sed -n '/[a-z]/p' numbers.txtPrint lines containing at least one lowercase letter
Match the beginning of a line^sed -n '/^step/p' numbers.txtPrint lines starting with step
Match the end of a line$sed -n '/5$/p' numbers.txtPrint lines ending with 5
Match any single character.sed -n '/step ./p' numbers.txtPrint lines containing step followed by at least one character
Match one or more digits, basic regex[0-9]\+sed -n '/[0-9]\+/p' numbers.txtPrint lines containing one or more digits
Match one or more digits, extended regex[0-9]+sed -E -n '/[0-9]+/p' numbers.txtSame as above, but using extended regular expressions
Note

By default, sed uses basic regular expressions. With basic regular expressions, some symbols must be escaped. For example, one or more repetitions is written as: \+.

With the option -E, sed uses extended regular expressions, so the same pattern can be written more naturally: +.

For this reason, many modern examples use:

sed -E 'command' file

Common extended regular expression syntax:

PatternMeaning
.any single character
[abc]one character: a, b, or c
[0-9]one digit
[a-z]one lowercase letter
^beginning of line
$end of line
+one or more repetitions
*zero or more repetitions
?zero or one repetition
`ab`
( ... )group

Example:

sed -E -n '/^(step|time)/p' numbers.txt

prints lines starting with either step or time.

The & symbol in replacements¶

In the replacement part of a substitution, & means “the entire matched text”.

Example:

cat > values.txt
value 10
value 20
value 30
^D

Put brackets around numbers:

sed -E 's/[0-9]+/[&]/' values.txt

Output:

value [10]
value [20]
value [30]

Here & is replaced by the matched number.

Another example:

sed -E 's/value/& =/' values.txt

Output:

value = 10
value = 20
value = 30

Escaping special characters¶

Some characters have special meaning in sed patterns or replacements.

Common examples:

CharacterMeaning
.any character
*repetition
[ ]character class
^beginning of line
$end of line
/default delimiter
&matched text in replacement
\escape character

To match a literal dot, escape it:

sed 's/0\.1/0.2/' file.txt

Without escaping, . means any character.

To replace a literal &, escape it in the replacement:

echo "A and B" | sed 's/and/\&/'

Output:

A & B

To replace /, either escape it:

sed 's/\/old\/path/\/new\/path/' file.txt

or use another delimiter:

sed 's|/old/path|/new/path|' file.txt

Insert, append, and change lines¶

sed can insert, append, or replace whole lines.

Commands:

CommandMeaning
iinsert before matching line
aappend after matching line
cchange matching line

Create a file:

cat > config.txt
dt = 0.01
nsteps = 100
viscosity = 0.1
^D

Insert before a line¶

Insert a line before nsteps:

sed '/nsteps/i output_interval = 10' config.txt

Output:

dt = 0.01
output_interval = 10
nsteps = 100
viscosity = 0.1

Append after a line¶

Append a line after nsteps:

sed '/nsteps/a output_interval = 10' config.txt

Output:

dt = 0.01
nsteps = 100
output_interval = 10
viscosity = 0.1

Change a line¶

Replace the line containing nsteps:

sed '/nsteps/c nsteps = 1000' config.txt

Output:

dt = 0.01
nsteps = 1000
viscosity = 0.1
Note

Syntax for multi-line insertions can differ slightly between GNU sed and macOS sed.

For simple one-line insertions, the examples above are usually sufficient in modern implementations.

Multiple commands¶

You can apply multiple sed commands in one call.

Use ;:

sed 's/cow/goat/g; s/dog/cat/g' animals.txt

or use multiple -e options:

sed -e 's/cow/goat/g' -e 's/dog/cat/g' animals.txt

Example:

sed -e '/WARNING/d' -e 's/INFO/MESSAGE/' log.txt

This:

  1. deletes lines containing WARNING;

  2. replaces INFO with MESSAGE.

Reading commands from a sed script¶

For more complex edits, put commands in a file.

Create a sed script:

cat > edit.sed
s/INFO/MESSAGE/g
s/WARNING/CAUTION/g
/ERROR/d
^D

Apply it:

sed -f edit.sed log.txt

This is useful when edits become too long to write on one command line.

Common sed commands¶

CommandMeaning
s/old/new/replace first occurrence of old with new on each line
s/old/new/greplace all occurrences of old with new on each line

Summary¶

sed 's/old/new/' file.txt                 # replace first occurrence on each line
sed 's/old/new/g' file.txt                # replace all occurrences on each line
sed 's|/old/path|/new/path|g' file.txt    # use another delimiter for paths

sed -n '3p' file.txt                      # print line 3
sed -n '2,5p' file.txt                    # print lines 2 to 5
sed -n '/pattern/p' file.txt              # print lines matching pattern

sed '3d' file.txt                         # delete line 3
sed '2,5d' file.txt                       # delete lines 2 to 5
sed '/pattern/d' file.txt                 # delete lines matching pattern

sed '/pattern/s/old/new/g' file.txt       # replace only on lines matching pattern
sed '/pattern/!s/old/new/g' file.txt      # replace only on lines not matching pattern

sed -E 's/[0-9]+/[&]/g' values.txt        # reuse matched text with &

sed '/pattern/i inserted line' file.txt   # insert line before pattern
sed '/pattern/a appended line' file.txt   # append line after pattern
sed '/pattern/c changed line' file.txt    # replace whole matching line

sed -e 's/a/b/g' -e 's/c/d/g' file.txt    # apply multiple commands
sed -f commands.sed file.txt              # read commands from a sed script

sed -i.bak 's/old/new/g' file.txt         # edit in place and keep backup

Exercise¶

Create this input file:

cat > inputfile
# Simulation parameters
dt = 0.01
nsteps = 100
restart = false
output_interval = 10
path = /home/m.sega/data
# restart = false
^D

Try the following commands:

sed 's/dt = 0.01/dt = 0.005/' inputfile
sed 's/^nsteps = .*/nsteps = 1000/' inputfile
sed 's|/home/m.sega/data|/scratch/m.sega/data|' inputfile
sed '/^[[:space:]]*#/!s/restart = false/restart = true/' inputfile
sed -n '2,5p' inputfile
sed '/^#/d' inputfile
sed -E 's/^([a-z_]+) = (.*)$/\1 -> \2/' inputfile

Then create a modified copy:

sed -e 's/^dt = .*/dt = 0.005/' \
    -e 's/^nsteps = .*/nsteps = 1000/' \
    -e 's|/home/m.sega/data|/scratch/m.sega/data|' \
    -e '/^[[:space:]]*#/!s/restart = false/restart = true/' \
    inputfile > inputfile_modified

Inspect it:

cat inputfile_modified

Only after checking the result, replace the original file:

mv inputfile_modified inputfile
